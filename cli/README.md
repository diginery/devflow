# DevEx CLI

A command-line tool for generating standardized software projects from reusable templates and ensuring they follow predefined development standards.

```bash
# Installation
npm install
npm run build
npm link

# Usage
devex list # show available templates
devex info <template> # show template metadata
dexex create <name> -t <template> # generate a project
devex validate <name> t <template> # check project standards
```
